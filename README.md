# VHDL / Vivado Projects

A collection of VHDL projects developed and simulated with AMD/Xilinx Vivado.

## Projects

| Project | Description |
|---|---|
| [Voting Machine](./voting-machine/) | Finite-state-machine voting controller with three counters |
| [Priority Mux](./priority-mux/) | Priority multiplexer implemented in VHDL |

Each project contains RTL source code, a testbench, and relevant simulation documentation.
